Definição rápida

Closure é quando uma função lembra do escopo onde nasceu, mesmo depois que esse escopo já terminou. É o que permite "variáveis privadas" em JavaScript.

Mnemônico: closure = função + a mochila das variáveis ao redor dela.

Exemplo 1 — contador

function criarContador() {
  let n = 0; // vive na "mochila" da closure
  return () => ++n;
}

const c = criarContador();
console.log(c()); // 1
console.log(c()); // 2

Por que funciona?

A arrow function retornada continua referenciando n. Como existe referência, o garbage collector não limpa n.

Exemplo 2 — entrevista

for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 3, 3, 3 😅
}

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j), 100); // 0, 1, 2 ✓
}

Com var, há uma única variável compartilhada. Com let, cada iteração ganha seu próprio binding — cada timeout fecha (closure) sobre um valor diferente.

Se perguntarem "para que serve closure?", responda: encapsulamento, factories, debounce, memoize.
