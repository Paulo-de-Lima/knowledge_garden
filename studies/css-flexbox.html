A ideia em 10 segundos

Flexbox alinha coisas em um eixo por vez. Defina o container como display: flex e escolha a direção. O resto é consequência.

.lista {
  display: flex;
  gap: 12px;               /* espaço entre itens */
  justify-content: center; /* eixo principal */
  align-items: center;     /* eixo transversal */
}

Eixo principal vs transversal

Se flex-direction: row, o principal é horizontal. Se for column, o principal vira vertical — e o justify-content passa a empilhar na vertical.

Holy grail em 10 linhas

.page { display: flex; min-height: 100vh; }
aside { width: 240px; }
main  { flex: 1; } /* ocupa o resto */
Truque que uso sempre: flex: 1 no filho = "ocupe todo o espaço que sobrar".
Não decore tudo — decore 4: display:flex, direction, justify, align. O resto consulte.
