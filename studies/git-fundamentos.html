Setup mínimo

git init
git add .
git commit -m "primeiro commit"

Fluxo do dia a dia

git status                 # o que mudou?
git add arquivo.js         # prepara
git commit -m "feat: ..."  # registra
git push origin main       # envia

Branches sem medo

git checkout -b feat/minha-ideia
# ... codar ...
git checkout main
git merge feat/minha-ideia

Desfazer sem pânico

  • git restore arquivo — descarta mudança ainda não commitada
  • git reset --soft HEAD~1 — desfaz o último commit, mantém o código
  • git log --oneline --graph — entende o histórico
Regra de ouro: nunca dê push --force em branch compartilhada.
